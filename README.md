# bellabeat-fitness-tracker
**Bellabeat Data Analysis** is a Python-based data analysis project exploring smart device usage and user activity. It analyzes daily steps, calories burned, sleep patterns, weight trends, and relationships between health metrics using ** Excel, and data visualization**.
# Bellabeat Data Analysis 
 
## Overview 
 
Data analysis project exploring smart device usage and activity data to understand user activity, sleep, weight, and daily habits. 
 
## Analysis 
 
* Daily activity and steps 
* Calories burned 
* Sleep patterns 
* Weight trends 
* Activity and user behavior 
* Relationships between different health metrics 
 
## Tools 
 
* Python 
* Pandas 
* Excel 
* Data Visualization
